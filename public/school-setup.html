학교 기기에 한꺼번에 설치하기

오디세이 런은 설치 파일 없이 웹 주소 하나로 열려요. 계정·서버가 없고, 기록은 각 기기의 브라우저에만 저장돼요. 아래 방법 중 학교 환경에 맞는 것을 고르세요.

1. 학생에게 주소 나눠 주기

교실 화면에 이 QR을 띄우거나, 아래 문구를 그대로 복사해 패들렛·구글 클래스룸·밴드·하이클래스에 올려 주세요.

게임 안 홈 화면의 QR 버튼으로도 큰 QR을 띄울 수 있어요.

2. 크롬북: 관리 콘솔에서 강제 설치

학교 크롬북을 Google 관리 콘솔로 관리한다면, 담당 선생님이 한 번 설정해 모든 크롬북 선반(작업 표시줄)에 앱을 넣을 수 있어요.

  1. admin.google.com → 기기 → Chrome → 앱 및 확장 프로그램 → 사용자 및 브라우저
  2. 왼쪽에서 학생 조직 단위를 고르세요.
  3. 오른쪽 아래 ＋ → URL로 추가(웹 앱 추가)를 누르고 주소를 넣으세요.
    https://gmlduqzhd123-lab.github.io/Odyssey-Run/
  4. 설치 정책을 강제 설치 또는 강제 설치 + ChromeOS 작업 표시줄에 고정으로 고르고 저장하세요.

메뉴 이름은 관리 콘솔 버전에 따라 조금 다를 수 있어요. 적용까지 몇 분에서 하루가 걸릴 수 있고, 학생이 크롬북에 다시 로그인하면 빨리 반영돼요.

3. 윈도우 노트북 (크롬·엣지)

그룹 정책이나 인튠(Intune)으로 관리한다면 WebAppInstallForceList 정책에 아래 값을 넣으면 크롬·엣지에 앱이 자동으로 설치돼요.

웨일 브라우저를 쓰는 학교는 웨일 관리 도구의 웹 앱 배포 기능을 확인해 주세요. 관리 도구가 없다면 4번처럼 기기마다 설치해도 돼요.

4. 기기마다 직접 설치 (1분)

  • 크롬·엣지·웨일 (PC·크롬북·안드로이드): 게임 주소를 열고 주소창 오른쪽의 설치 아이콘, 또는 메뉴 → 앱 설치(홈 화면에 추가)를 누르세요.
  • 아이패드·아이폰: 사파리로 열고 공유 → 홈 화면에 추가. 학교 MDM을 쓴다면 같은 주소로 웹 클립을 배포할 수 있어요.

설치하면 화면이 꽉 차고, 브라우저가 오래 쓰지 않은 사이트의 기록을 지우는 일도 줄어요.

5. 와이파이가 약한 교실이라면

수업 전에 각 기기에서 설정 → 섬 다운로드·업데이트를 한 번 눌러 두면, 인터넷이 끊겨도 네 개의 섬을 모두 달릴 수 있어요.

한 기기를 여러 학생이 함께 쓴다면 항해사 → 번호로 한 번에 만들기로 1번~30번 항해사를 만들어 두세요. 학생은 자기 번호를 골라 시작해요.

기록은 기기 밖으로 나가지 않아요. 기기를 초기화하기 전에는 설정 → 반 전체 내보내기로 백업해 주세요.
