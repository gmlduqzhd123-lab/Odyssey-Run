# 오디세이 런: 이타카로!

**Odyssey Run: Road to Ithaca** — 오디세우스가 네 섬을 달려 고향으로 돌아가는 2D 러닝게임입니다. 로그인, 외부 서버, DB 없이 PC와 스마트폰 브라우저에서 실행합니다.

출항의 해변 → 키클롭스의 동굴 → 아이올로스의 바람 섬 → 세이렌의 바다 → 이타카 항구. 한 섬은 24,000px, 피해·추락 없는 플레이는 약 75초입니다. 섬마다 별빛 100개와 지도 3개를 배치했습니다. 사용자 제공 캐릭터·아이템 이미지, 자체 SVG 배경과 사용자 제공 Suno 배경음악·합성 효과음을 포함합니다.

## 실행

Node **22.12 이상**(검증 환경: 24.19.0), npm **10 이상**이 필요합니다. 의존성은 `package-lock.json`으로 고정합니다.

```sh
npm ci
npm run dev
```

Vite가 출력한 로컬 주소를 엽니다. 로컬 개발 서버는 운영 배포 서버가 아닙니다.

```sh
npm run format      # 코드 자동 정렬 (CI는 format:check로 확인)
npm run typecheck   # TypeScript 검사
npm test            # 물리·점수·저장·코스 검증
npm run build       # 타입 검사 후 dist/ 생성
npm run preview     # 빌드 산출물 로컬 확인
npm run test:browser # 실행 중인 로컬 서버에서 Chromium 검증
npx tsx scripts/edge-qa.ts # QA_URL의 빌드에서 오류·저장 차단·재시작 검증
npx tsx scripts/performance-qa.ts # QA_URL의 빌드에서 10초 실시간 성능 측정
```

브라우저 검증은 `/usr/bin/chromium`을 기본 사용합니다. 다른 설치 경로는 `CHROMIUM_PATH`, 검증 주소는 `QA_URL`로 지정합니다. Playwright는 개발 의존성이고 게임 런타임에 포함되지 않습니다. 브라우저 검증은 수 분 걸릴 수 있습니다. 실측에서 Canvas 약 60fps, 관리형 환경의 소프트웨어 WebGL 약 29fps를 확인하여 게임 기본 렌더러로 Canvas를 사용합니다. 전체 코스는 Canvas에서 검증했습니다. 실제 모바일 기기의 성능은 아직 확인하지 않았습니다. `artifacts/`에 스크린샷과 결과를 남깁니다.

## 조작

| 행동 | PC | 터치 |
|---|---|---|
| 점프 | Space / ↑ 새로 누르기 | 점프 새로 누르기 |
| 2단 점프 | 공중에서 다시 누르기 | 공중에서 다시 누르기 |
| 슬라이드 | ↓ 누르고 유지 | 슬라이드 누르고 유지 |
| 일시정지 | P / Esc | Ⅱ 버튼 |
| 메뉴 | Tab / Shift+Tab / Enter | 메뉴 버튼 |

길게 눌러도 점프를 반복하지 않습니다. 점프와 슬라이드를 동시에 입력하면 공간이 있을 때 점프합니다. 낮은 천장 아래에서 슬라이드를 놓아도 안전하게 통과할 때까지 낮은 자세를 유지합니다. 가로 화면을 권장하며, 모바일 세로 화면·탭 숨김·포커스 상실 시 정지합니다. 계속하기를 누르면 3초 카운트다운 후 재개합니다.

## 점수와 진행

`floor(최고 전진거리 / 10) + 별빛 × 10 + 해당 판 지도 × 100 + 완주 시 500` (최대 **4,200점**).

완주 ★, 같은 판의 별빛 70개 이상 ★, 같은 판의 HP 손실 0회 ★입니다. 사과로 회복해도 HP 손실 이력은 남습니다. 방패 방어는 HP 손실이 아닙니다. 다음 섬은 이전 섬을 한 번 완주하면 열립니다. 별빛은 한 판의 점수이며 소비 화폐가 아닙니다.

지도 조각은 기본 이동, 높은 2단 점프, 낮은 슬라이드 경로에서 찾습니다. 지도 도감에서 아홉 개의 짧은 귀환 이야기를 읽을 수 있습니다. 지도 9개 수집과 이타카 귀환은 별도로 표시합니다.

## GitHub Pages

게임 주소: [오디세이 런: 이타카로!](https://gmlduqzhd123-lab.github.io/Odyssey-Run/)

연결 저장소: [gmlduqzhd123-lab/Odyssey-Run](https://github.com/gmlduqzhd123-lab/Odyssey-Run). 기본 브랜치는 `main`이며, 프로젝트 Pages 빌드 경로는 **`/Odyssey-Run/`**입니다. 구현 당시 작업 공간은 빈 프로젝트였으며, 제공된 GitHub 저장소도 기존 커밋이 없는 상태임을 확인했습니다.

- 기본 `base`는 연결된 저장소에 맞춘 `/Odyssey-Run/`입니다. 개발·미리보기에서도 Vite가 출력하는 이 하위 경로 주소를 엽니다. 다른 경로는 `PAGES_BASE`로 덮어쓸 수 있습니다.
- `.github/workflows/pages.yml`은 `GITHUB_REPOSITORY`에서 실제 저장소 이름을 읽습니다. 프로젝트 Pages는 `/<실제 저장소 이름>/`, `<실제 소유자>.github.io`와 정확히 일치하는 사용자/조직 Pages 저장소는 `/`로 빌드합니다.
- [저장소 Pages 설정](https://github.com/gmlduqzhd123-lab/Odyssey-Run/settings/pages)에서 **Source: GitHub Actions**를 선택합니다. 이 저장소는 사용자가 GitHub Actions 방식으로 활성화했으며 실제 배포·접속을 확인했습니다. 이후 main/master 푸시 또는 수동 workflow 실행으로 배포합니다. 필요하면 [Actions](https://github.com/gmlduqzhd123-lab/Odyssey-Run/actions)에서 워크플로를 수동 실행합니다. 워크플로 실행 결과와 실제 접속 검증은 `QA.md`의 GitHub 연동 기록에 별도로 남깁니다.
- 별도 하위 경로나 사용자 도메인이 필요하면 `PAGES_BASE`와 workflow의 경로 계산을 실제 구성에 맞춰 수정합니다.

```sh
PAGES_BASE=/Odyssey-Run/ npm run build
npm run preview
```

기본 경로 외의 base로 빌드했다면 미리보기에도 동일한 `PAGES_BASE`를 전달하세요. 예: `PAGES_BASE=/다른-경로/ npm run preview`. 해당 하위 경로의 시작 화면, 전체 메뉴, 자산, 새로고침을 확인하세요. 서버 라우팅이 필요 없는 단일 페이지 장면 전환입니다. JS·CSS·SVG는 같은 base를 사용하며 외부 CDN을 사용하지 않습니다. CI는 설치 → 타입 검사 → 테스트 → 빌드 → 정적 산출물 배포 순서입니다.

## 저장·기록 이동

기록은 이 기기와 브라우저에 저장돼요. 기록 파일로 옮길 수 있어요.

- 저장 키: `odyssey-run:<배포 base 경로>:save`. 백업은 여기에 `:backup`을 붙입니다.
- 완료·최고 점수·최고 평점·최고 별빛·지도 ID·설정·조작 안내 상태·최근 섬·저장 시각을 localStorage에 저장합니다.
- 성공/실패 결과가 확정된 판만 반영합니다. 도중에 메뉴로 나가거나 새로고침하면 그 판의 임시 진행은 버립니다.
- 저장 차단·용량 초과 시 메모리에서 계속 플레이하며 경고를 표시합니다. 설정의 **기록 내보내기**로 현재 유효 진행을 보관하세요.
- 손상·미지원 버전 원본은 자동으로 덮어쓰지 않습니다. 설정에서 보존된 원본을 내려받거나, 유효 파일을 복원하거나, 초기화를 선택할 수 있습니다.

다른 브라우저로 이동할 때는 설정에서 `odyssey-run-save-YYYYMMDD.json`을 내보내고 대상 브라우저에서 가져옵니다. UTF-8 JSON, 최대 64KiB입니다. 버전·필수 필드·타입·고유 ID·중복·수치·진행 순서를 검사한 후 진행 요약을 보여 줍니다. **이 기록으로 복원**을 눌러야 교체하며 기존 원본은 전용 백업 키에 보관합니다. 저장 실패 시 기존 기록을 유지합니다. 초기화는 확인 후 이 게임의 진행·설정·백업만 제거합니다.

개인정보 입력, 계정, 광고, 분석 SDK, 외부 추적은 없습니다. 기기 간 자동 동기화는 없습니다. 배포 경로를 바꾸면 별도 저장 공간으로 취급하므로 먼저 기록 파일을 내보내세요.

## 구조와 문서

- `src/player/runner.ts`: 고정 간격 물리와 판 상태. Phaser의 물리 플러그인을 중복 실행하지 않습니다.
- `src/input/controls.ts`: 키보드·pointerId별 터치의 공통 행동.
- `src/levels/courses.ts`, `src/config.ts`: 고정 코스와 밸런스 값.
- `src/systems/`: 점수·음향. `src/storage/`: 검증·기록 병합·원본 보존.
- `src/scenes/World.ts`: Phaser 렌더링·자산 로딩. `src/ui/`: 접근 가능한 DOM 메뉴와 HUD.
- `public/assets/`: 자체 SVG. `scripts/create-assets.py`: 재생성 스크립트(Python 3, 빌드 필수 아님).
- `PRD.md`: 구현 기준. `ASSET_CREDITS.md`: 자산·라이선스. `QA.md`: 검증 근거와 제한.

Phaser **3.90.0** 공식 문서의 [Scene](https://docs.phaser.io/api-documentation/3.90.0/class/scene)과 [Arcade Physics](https://docs.phaser.io/api-documentation/3.90.0/class/physics-arcade-arcadephysics)를 확인했습니다. 이 게임은 천장 공간·입력 유예·추락 복구의 재현 가능한 검증을 위해 가벼운 고정 시간 시뮬레이션을 사용하고 Phaser Scene.update를 유일한 게임 루프로 사용합니다. 이 게임에 필요한 2D 그리기 기능은 Canvas에서 모두 동작합니다.

## 사용자 제공 이미지

캐릭터 10장과 아이템·상징 10장을 웹용 WebP로 적용했습니다. 붉은 망토의 오디세우스가 제목과 플레이에 등장합니다. 도감의 **지도 조각 / 여정의 인물 / 아이템과 상징**에서 나머지 그림과 설명을 볼 수 있습니다. 인물 카드는 이야기를 여는 버튼이며 조종 캐릭터를 바꾸지 않습니다. 방패·날개 신발·자석·사과·지도의 효과와 저장 형식은 유지합니다.

원본 20장은 약 33.4MB, 현재 20장 배포 이미지 합계는 약 2.00MB입니다. 종횡비·투명 배경을 보존하며, 도감 이미지는 지연 로딩합니다. 제공된 캐릭터 원본은 인물별 한 장입니다. 달리기 모션 개선 요청에 따라 기존 오디세우스 그림을 참고해 **서로 다른 자세 8개의 투명 달리기 시트**를 추가 제작했습니다. 지상에서는 14fps로 다리를 뻗고, 딛고, 무릎을 올리는 주기를 재생합니다. 점프·슬라이드·완주와 제목·인물 도감에는 기존 그림을 사용합니다. 일시정지와 재개 카운트다운 중에는 달리기 프레임도 멈춥니다. 달리기 시트는 선명도 개선으로 원본 해상도 1536×1024(약 1.30MB)를 사용하며 정보는 `docs/runner-animation-manifest.json`에 있습니다.

출처·사용 위치는 `ASSET_CREDITS.md`, 원본 파일명과 해시는 `docs/user-art-manifest.json`에 있습니다. 일반 `npm ci`/`npm run build`는 준비된 WebP만 사용합니다. 원본 ZIP으로 다시 변환할 때만 ImageMagick과 unzip을 설치하고 다음을 실행합니다.

```sh
node scripts/prepare-user-art.mjs '캐릭터 이미지.zip' '아이템 이미지.zip'
```

지형·오브젝트 ZIP의 원화 시트 5장도 포함했습니다. 모래·동굴 바위·유적 무늬와 나무 발판을 실제 지형에 사용하고, 풍경은 섬 선택·준비·이타카 엔딩에 표시합니다. **도감 → 풍경과 원화**에서 다섯 시트의 전체 그림을 열고 **원본 크기로 확대**할 수 있습니다. 확대 그림은 터치 드래그 또는 포커스 후 방향키로 이동합니다.

원화에는 다른 섬·몬스터·추가 공격 설명도 있지만, 이 게임의 세 코스와 기존 규칙은 유지합니다. 배경에 그려진 발판이 실제 길로 보이지 않도록 풍경 원화는 메뉴와 엔딩에 배치했습니다. 원본 15.76MB → 웹용 시트 3.60MB이며, 원본 해상도 1536×1024를 유지한 WebP 품질 90 인코딩입니다. `docs/terrain-art-manifest.json`에 출처·해시를, `src/assets/terrain.ts`에 사용 영역을 기록합니다.

```sh
# 선택적 오프라인 재인코딩 — 일반 빌드에는 필요 없음
node scripts/prepare-terrain-art.mjs '플랫포머 게임 지형·오브젝트 도감.zip'
# 빌드/preview 실행 후 Chromium 에뮬레이션 검증
npx tsx scripts/terrain-qa.ts
```

달리기 모션 검증: preview를 실행한 뒤 `npx tsx scripts/runner-animation-qa.ts`. 실제 Canvas에 그려진 8개 자세, 카운트다운·일시정지의 프레임 정지, 점프/슬라이드 후 달리기 복귀, 재시작·제목 화면 복귀와 모바일 에뮬레이션을 확인합니다.

## 선명도와 움직임

게임 규칙은 기본 960×540 좌표를 사용하며, 화면 비율에 맞춰 최소 시야를 보존하고 더 넓거나 높은 배경을 표시합니다. Canvas는 화면 크기와 최대 2의 기기 배율에 맞춰 렌더링하며, 렌더 배율 최대 4/약 829만 픽셀 한도로 과도한 확대와 메모리 사용을 제한합니다. SVG 배경·장애물은 2배로 준비하고, 배경은 중간 저해상도 캔버스 없이 직접 그립니다. 안내 글자와 획득 알림도 표시 배율에 맞춰 그립니다. 일러스트의 부드러운 보간은 유지합니다.

기본 먼 배경은 초당 8px, 가까운 배경은 20.8px만 이동합니다. **움직임 줄이기**를 켜면 장식 배경 스크롤·수집물의 상하 흔들림·바람 입자 이동과 떠오르는 알림을 멈춥니다. 달리기·점프와 실제 장애물·발판의 움직임은 유지합니다. 무적 상태는 일정한 투명도로 표시합니다.

달리기 그림의 위치는 프레임별로 보정하여 가로 흔들림을 줄였습니다. 화면 회전과 창 크기 변경 후에도 전체 시야와 버튼 위치를 유지합니다. 전체 화면/크기 변경 검증: `npx tsx scripts/viewport-qa.ts`. 이전 선명도·모션 계측은 `QA_PHASE=after npx tsx scripts/display-qa.ts`를 사용할 수 있습니다. 검증 환경·전후 비교와 실제 장치 미실행 항목은 QA.md에 기록합니다.

## 실행 점검과 오류 재현

```sh
# preview 실행 후 키보드·복원 경쟁 상태·손상 기록 보존 검증
npx tsx scripts/audit-qa.ts
# 가상 시계 없이 약 75초 동안 실제 키보드 입력으로 해변 완주
npx tsx scripts/realtime-qa.ts
# 실패 결과·재도전·기존 최고 기록 보존 검증
npx tsx scripts/failure-qa.ts
```

## 열 가지 모험 요소와 종료

- 점프로 **높은 유적길**을 고르면 별빛 다섯 개와 숨은 이야기를 만납니다. 아래 길은 기존 지상 항로입니다.
- 해변의 무너지는 부두, 동굴의 거인 손, 바람 섬의 구름 징검다리는 섬마다 다른 하이라이트입니다. 카메라/배경은 고정합니다.
- 배·부엉이·왕관 **별자리 9개**, 가까스로 피한 **회피 문양/알림**, 키클롭스의 바위로 석상병을 맞히는 **유도 격파**가 있습니다. 바위를 던지기 전에 뛰면 조준 높이가 달라집니다.

## 화면을 꽉 채우는 표시

PC와 스마트폰에서 게임은 브라우저의 현재 가로·세로를 모두 사용합니다. 최대 1,440px 제한과 바깥 여백/둥근 테두리를 제거하고, 하단 출처는 메뉴에만 표시해 플레이 영역을 가리지 않습니다. 화면이 넓으면 좌우 시야를, 세로 공간이 더 크면 위쪽 배경을 확장합니다. 최소 960×540 시야와 캐릭터의 가로 20% 위치를 유지하며 그림을 찌그러뜨리거나 코스를 잘라 확대하지 않습니다.

상단 메뉴 또는 플레이 오른쪽 위의 **⛶ 전체 화면** 버튼을 누르면 지원 브라우저에서 주소창을 숨기는 전체 화면을 요청합니다. 다시 누르거나 브라우저의 전체 화면 나가기 기능으로 복귀합니다. 지원하지 않거나 요청이 거부되면 안내 후 현재 브라우저 영역으로 플레이합니다. iOS 등에서는 설치한 홈 화면 앱과 브라우저의 지원 차이가 있습니다. PWA는 fullscreen/standalone 표시를 요청하며 실제 운영체제 적용은 기기·브라우저에 따릅니다.

노치/홈 표시줄 안전 영역, 모바일 세로 정지/회전 복귀, 주소창 높이 변화와 창 크기 변경을 처리합니다. 이동/점프/충돌·9개 코스·점수·기록 저장 형식은 유지합니다. 검증: `npx tsx scripts/viewport-qa.ts`, `QA_ENGINE=webkit npx tsx scripts/viewport-qa.ts`(설치된 WebKit 필요), `QA_PREFIX=viewport-play QA_DESKTOP_DPR=1 npx tsx scripts/contact-qa.ts`(세 섬 키보드/터치 완주와 저장/복원).

- **결과 QR 연속 스캔**: 대회 순위표의 「📷 결과 QR 연속 찍기」로 카메라를 켜 둔 채 학생 결과 QR을 차례로 찍습니다. 판독 라이브러리(jsQR)는 브라우저에 판독 기능이 없을 때만 받습니다. 「순위 CSV 내보내기」는 엑셀에서 바로 열립니다.
- **반 전체 백업**: 설정 → 「반 전체 내보내기/가져오기」로 모든 항해사 기록과 대회 순위를 한 파일로 옮깁니다. 가져오기는 미리보기 후 합치기만 하고 지우지 않습니다.
- **가벼운 첫 로딩**: 영어 사전·QR 판독기는 필요할 때만 받는 별도 파일이고, Phaser는 별도 파일로 두어 업데이트할 때 바뀐 게임 코드만 다시 받습니다(오프라인 업데이트도 같은 파일은 기기 안에서 복사).

## 기록 보호와 대회 확인 (2026-10-27)

- **기록 보호**: 기록을 남긴 뒤 브라우저에 영구 저장을 요청합니다. 설정의 「반 전체 백업」 칸에 마지막 백업 날짜와 보호 상태를 보여 주고, 여러 항해사나 대회가 있는 기기에서 백업이 없거나 14일이 지나면 시작 화면에서 일주일에 한 번 알려 줍니다. 아이폰·아이패드 사파리 탭에서는 홈 화면 설치를 안내합니다(설치하지 않으면 7일 동안 열지 않을 때 사파리가 기록을 지울 수 있습니다).
- **대회 결과 확인**: 결과 코드는 서버 서명이 없어 손으로 만들 수 있습니다. 점수·시간·별빛·지도·완주가 실제 달리기로 나올 수 없는 조합이면 순위표와 CSV에 「⚠ 확인 필요」를 붙이고, 선생님이 「빼기」로 그 기록만 지울 수 있습니다. 참가 QR에 비밀 값을 넣는 방식은 참가하는 학생 모두가 그 값을 보게 되므로 위조를 막지 못해 넣지 않았습니다.
- **느린 기기**: 그래픽 품질이 「자동」일 때 3초 이상 평균 40fps 아래로 떨어지면 그 기기는 가벼운 그래픽으로 바꾸고 한 번 알려 줍니다. 설정에서 다시 「자동」을 고르면 다시 시도합니다.
- **실기기 점검**: `docs/device-checklist.md`에 에뮬레이션으로 확인할 수 없는 14개 항목과 기록표가 있습니다.

```sh
npm run test:classroom   # 두 탭 합치기, 반 전체 백업·복원, 백업 알림, 가짜 카메라 QR 스캔·위조 표시·빼기·CSV
```

CI는 빌드 한 번 뒤에 브라우저 검사 6묶음(structures, release, offline, i18n, classroom, loading·update)을 동시에 돌리고, 모두 통과해야 배포합니다.

## 세로 플레이·진행 현황판·글꼴·보안 (2026-10-28)

- **세로 플레이**: 휴대폰을 세로로 들어도 멈추지 않고 플레이합니다. 위에 점수·체력, 가운데 16:9 게임 화면, 아래에 큰 점프·슬라이드 버튼이 놓입니다. 플레이 중 방향을 바꾸면 일시정지되고, 「계속하기」로 이어서 달립니다.
- **작은 가로 휴대폰**: 별빛·지도·도전 칩을 화면 아래 버튼 사이(땅 부분)로 옮겨, 장애물이 나타나는 하늘을 가리지 않습니다. 카운트다운 배경을 진하게 해 숫자가 뒤 글자와 섞이지 않습니다.
- **학생별 진행 현황**: 항해사 화면 → 「📋 학생별 진행 현황」에서 학생마다 섬별 완주·별점·최고 점수, 지도·도장·퀴즈, 총점, 마지막 저장일을 표로 보고 CSV로 내보냅니다.
- **글꼴**: 게임 글자만 뽑은 글꼴(약 140KB, Pretendard 기반 「Odyssey UI」)을 함께 보내 윈도우·맥·아이폰·크롬북에서 같은 모양과 크기로 보입니다. 오프라인 핵심 파일에 포함됩니다. 화면 문구를 새로 넣어 글꼴에 없는 글자가 생기면 단위 테스트가 실패하므로 `scripts/subset-font.py`로 다시 만들어 주세요.
- **보안 정책(CSP)**: 배포용 페이지는 게임 자체 파일 밖의 스크립트를 실행하지 않습니다. `npm run test:classroom`이 HTML이 섞인 이름·대회명과 망가진 공유 링크를 넣어 보고, 보안 정책 위반이 없는지 확인합니다.

## 데이터 절약·읽기 쉬운 글자·세로 확대·간편 업데이트·저장 공간 (2026-10-28)

- **데이터 절약**: 큰 그림 25개를 같은 크기·같은 투명 영역(충돌 판정 그대로)으로 다시 압축했습니다(`scripts/compress-art.py`). 몬스터 1.4MB→0.36MB, 오디세우스 달리기 1.3MB→0.36MB. 섬 음악은 섬을 고를 때가 아니라 실제로 달리기 시작할 때 받고, 브라우저의 데이터 절약 모드에서는 받지 않습니다. 선생님용 QR 판독기는 오프라인 핵심 파일에서 빠져 섬 다운로드와 함께 받습니다. 오프라인 핵심 3.2MB→2.7MB, 섬 공통 8.0MB→4.8MB.
- **읽기 쉬운 글자**: 흐린 회녹색 글자 약 30종을 웹 접근성 기준(작은 글자 4.5:1)에 맞게 진하게 했습니다. 글자 배치 검사(`npm run test:layout`)가 이제 글자 대비도 검사합니다(단색 배경 위 글자 대상).
- **세로 플레이 확대**: 세로 화면의 게임 화면을 16:9에서 4:3으로 키우고, 보이는 가로 범위를 좁혀(960→720) 오디세우스와 장애물이 더 크게 보입니다. 앞쪽은 계속 약 1.6초 거리가 보입니다.
- **간편 업데이트**: 앱을 열 때 이미 받아 둔 새 버전이 있으면 바로 적용합니다. 쓰는 도중 새 버전이 오면 시작 화면에 「지금 업데이트」 버튼이 나옵니다. 진행 현황판과 업데이트 화면에 기기의 게임 버전을 표시합니다.
- **저장 공간**: 설정의 반 전체 백업 칸에 사용량(한도 약 5MB 중 몇 %)을 표시하고, 70%를 넘으면 시작 화면에서 주 1회 알립니다. 복원 전 사본은 그날 반 전체 내보내기를 한 뒤에만 정리할 수 있고, 손상된 기록의 원본 사본은 지우지 않습니다. 비교 항해 기록 압축은 예전 버전 기기와 백업 파일을 주고받지 못하게 되므로 하지 않았습니다.

## 더 많은 교실을 위해 (2026-10-29)

- **학교 기기 일괄 설치**: 설정 → 「🏫 학교 기기에 한꺼번에 설치하기」가 `school-setup.html`을 엽니다. 패들렛·클래스룸·밴드에 붙일 공유 문구와 QR, 크롬북 관리 콘솔의 강제 설치 순서, 윈도우 크롬·엣지 `WebAppInstallForceList` 값, 아이패드 웹 클립, 오프라인 준비를 한 쪽에 모았습니다. 스크립트 없는 정적 페이지입니다(서비스 워커는 게임 주소에만 게임 화면을 돌려줍니다).
- **번호로 한 번에 만들기**: 항해사 화면에서 「번호로 한 번에 만들기」를 펼쳐 1번~30번처럼 번호 항해사를 만듭니다(최대 40명, 있는 번호는 건너뜀). 다른 언어에서는 No. 1, Số 1, 1号, № 1처럼 그 언어로 만듭니다.
- **기기 설정 따르기**: 기기의 「동작 줄이기」를 켜면 게임 설정과 상관없이 움직임을 줄이고 설정 화면에 그렇다고 알려 줍니다. 「대비 높이기」·윈도우 고대비 테마에서는 메뉴 배경·글자·버튼 테두리를 진하게 합니다. 브라우저 기본 글자 크기를 키우면(16px보다 크면) 메뉴 화면을 그 비율로(최대 1.4배) 키웁니다. 휴대폰 운영체제의 글자 크기 설정은 브라우저마다 웹 페이지에 전달되는 방식이 달라 모든 기기에서 따라가지는 못합니다.
- **언어 5개**: 한국어·English·Tiếng Việt·中文·Русский. 사전은 고른 언어만 받고, 새 문구가 아직 번역되지 않았으면 영어로 보입니다. 베트남어·러시아어 글자는 그 글자가 화면에 나올 때만 받는 작은 글꼴 파일(약 19KB)에 있고, 중국어는 기기 글꼴을 씁니다. 세 언어 사전은 오프라인 핵심 파일이 아니라 섬 다운로드와 함께 받습니다. 사전 번역은 자동 번역 뒤 검사(같은 키·같은 자리표시자·한글 없음)를 거쳤고, 원어민 검토는 아직 하지 않았습니다.
- **게임패드·스위치**: 게임패드 A 또는 위 = 점프, B 또는 아래 = 슬라이드(누르는 동안), Start = 일시정지. 메뉴에서는 방향키로 버튼을 옮기고 A로 누릅니다. 보조 스위치가 보내는 Space·Enter로도 점프합니다.
- **그림으로 저장**: 기록 공유 화면의 「🖼 그림으로 저장」이 섬 그림·코스·점수·별점·별빛·지도를 담은 1200×630 PNG를 만듭니다. 이름은 「그림에 내 이름 넣기」를 켰을 때만 넣습니다. 서버로 보내지 않고 기기에서 만듭니다.

```sh
QA_LANG=vi npm run test:i18n   # vi·zh·ru 각각, 그림 저장·번호 항해사 화면 포함
QA_LANGS=ru QA_SAVES=played npm run test:layout
```

CI는 브라우저 검사에 i18n-vi-zh-ru와 layout-vi·zh·ru를 더했습니다.
