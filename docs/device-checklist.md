# 실기기 점검표

에뮬레이션(PC 크롬의 모바일 화면 흉내)으로는 확인할 수 없는 항목입니다. 학교에서 실제로 쓰는 기기로 한 번씩 확인하고, 결과를 아래 표에 적은 뒤 `QA.md`에 날짜와 함께 옮겨 주세요. 확인하지 못한 칸은 **미실행**으로 둡니다.

## 준비

- 주소: https://gmlduqzhd123-lab.github.io/Odyssey-Run/
- 확인 전에 설정 → 반 전체 내보내기로 기기의 기록을 백업해 두세요.
- 기기마다 기종·운영체제 버전·브라우저 버전을 적어 주세요.

## 점검 항목

| # | 항목 | 확인 방법 | 기대 결과 |
|---|---|---|---|
| D1 | 첫 화면 로딩 | 학교 와이파이에서 새로 열기 | 10초 안에 시작 화면, 오류 화면 없음 |
| D2 | 해변 한 판 | 처음부터 끝까지 달리기 | 끊김 없이 완주, 점프·슬라이드 터치가 바로 반응 |
| D3 | 자동 그래픽 품질 | 설정에서 그래픽 품질 「자동」으로 해변 한 판 | 느린 기기면 「그래픽을 가볍게 바꿨어요」 안내가 한 번 나오고 그 뒤로 부드러워짐. 빠른 기기면 안내 없음 |
| D4 | 발열·배터리 | 10분 연속 플레이 | 손으로 잡기 힘들 정도로 뜨겁지 않음, 배터리 10% 이하 소모 |
| D5 | 가로/세로 회전 | 플레이 중 세로로 돌리기 | 게임이 멈추고 「가로로 돌려」 안내, 가로로 돌리면 이어서 재개 |
| D6 | 전체 화면 | 머리말의 전체 화면 버튼 | 지원 기기는 전체 화면, 아이폰은 안내 문구 |
| D7 | 진동 | 설정에서 진동 켜고 피격·지도 획득 | 안드로이드: 짧은 진동 / 아이폰: 진동 없음(정상) |
| D8 | 홈 화면 설치 | 📲 앱 설치 또는 공유 → 홈 화면에 추가 | 아이콘으로 열면 주소창 없이 실행 |
| D9 | 오프라인 | 설정 → 섬 다운로드 후 비행기 모드로 다시 열기 | 받은 섬은 시작·완주 가능 |
| D10 | 결과 QR 연속 스캔 | 교사 기기에서 대회 순위표 → 📷 결과 QR 연속 찍기, 학생 화면의 결과 QR 3장 차례로 비추기 | 카메라 권한 요청 후 3명이 순위표에 들어감, 같은 QR은 한 번만 |
| D11 | 학생 카메라로 참가 | 학생 기기 기본 카메라 앱으로 참가 QR 찍기 | 게임이 대회 참가 화면으로 열림 |
| D12 | CSV | 순위 CSV 내보내기 → 엑셀/구글 시트로 열기 | 한글 깨짐 없음, 「확인 필요」 열 표시 |
| D13 | 기록 보호 | 설정 → 반 전체 백업 칸 | 아이폰·아이패드 사파리 탭에서는 홈 화면 설치 안내가 보임 |
| D14 | 두 탭 | 같은 기기에서 게임 탭 두 개 열고 한쪽에서 완주 | 다른 탭에 「다른 탭에서도 열려 있어요」 안내, 기록 유지 |
